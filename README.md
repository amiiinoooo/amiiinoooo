# Hi, I'm Amine Ben Nasrallah 👋

Computer Systems Engineering student at MedTech (South Mediterranean University) in Tunis 🇹🇳. I build embedded systems, networked apps, web apps and secure back-ends, and I'm interested in AI and data visualization.

- Built a voice-controlled smart house on STM32, driven by an LLM workflow
- Built RPS Arena, a multiplayer game over raw TCP/UDP with desktop and web clients
- Secured a JavaFX + MySQL hotel management app during my cybersecurity internship at Network Associates (summer 2025): BCrypt, e-mail 2FA, SQL-injection protection, brute-force lockout
- Currently learning: data structures & algorithms, Linux, and AI
- Ask me about: Java, Python, web development, app security
